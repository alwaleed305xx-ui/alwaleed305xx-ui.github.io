# 🧟 صايح — لعبة رعب كوميدية أونلاين

لعبة أونلاين مع الربع: واحد عشوائي يصير **الوحش** 🧟 والباقين **عيال** يحاولون يخلصون
مهام مضحكة ويهربون. المشكلة؟ **كل مهمة تسوي ضجة... والوحش يسمعها!** 😂

---

## ⚡ الطريقة السريعة — 4 خطوات وتلعب

1. **افتح المشروع**: من Unity Hub → **Add project from disk** → اختر مجلد `UnityGame` هذا
   (يشتغل على Unity 2022.3 أو أحدث — الحزم تتثبت تلقائياً)
2. من القائمة العلوية اضغط: **Sayeh → 🎮 Setup Everything (جهز اللعبة كاملة)**
   — تنبني لك الخريطة والوحوش والمهام والواجهة والشبكة **كلها بضغطة وحدة!**
3. اضغط **Play** ▶️ → زر **Host** → **Start Round** وجرب اللعبة فوراً
4. للتجربة مع شخص ثاني: سوّ **Build** (File → Build And Run) وشغّل نسخة Host ونسخة Join

> الأشكال الحالية مؤقتة (كبسولات ملونة بعيون حمراء 😈) عشان تلعب فوراً —
> بدّلها بأسيتاتك الحقيقية متى ما حبيت (الشرح تحت 👇)

---

## 🎮 فكرة اللعب

| الدور | وش يسوي |
|---|---|
| 🧟 **الوحش** (لاعب عشوائي واحد) | يطلع بشكل عشوائي من 3 وحوش، محبوس أول 10 ثواني، بعدها يصيد. يشوف **سهم أحمر** على شاشته يدله على أي ضجة! |
| 🏃 **العيال** (الباقين) | يخلصون 6 مهام مضحكة → يفتح باب الهروب → ينجون. اللي ينمسك يصير شبح 👻 يتفرج ويطير |

**الركض نفسه يسوي ضجة** — فامشِ بهدوء... أو اركض وتحمل العواقب 😈

### المهام الست المضحكة
1. 😱 **صايح بأعلى صوتك** — اضغط Space بسرعة 10 مرات... وكل صيحة توصل للوحش!
2. 🎤 **حفلة كاريوكي** — اضغط الحرف الصح (J/K/L)، وكل نشاز = ضجة قوية
3. 🕺 **ارقص على المنصة** — اضغط الأسهم وارقص على موسيقى صاخبة
4. 🍜 **اطبخ النودلز** — قلّب بـ E كل شوي، نسيت؟ إنذار الدخان يفضحك 🚨 (والتقدم يرجع لورا!)
5. 🐔 **امسك الدجاجة** — دجاجة هاربة تصارخ بأعلى صوتها وهي تهرب منك
6. 🚽 **صلّح دورة المياه المسكونة** — اضغط E بإيقاع هادئ، استعجلت = انفجار سيفون 💦

## 🎨 تركيب أسيتاتك الحقيقية (بدال الأشكال المؤقتة)

نزّل من **Window → Package Manager → My Assets**:

### الوحوش الثلاثة ⭐
افتح البريفاب `Assets/Sayeh/Prefabs/Monster.prefab` وبتلقى تحت `Skins` ثلاث أشكال مؤقتة:

| الشكل المؤقت | بدّله بموديل من |
|---|---|
| `Skin_Zombie_PLACEHOLDER` | 🧟 **FREE Zombie Male AAB** |
| `Skin_Mutant_PLACEHOLDER` | 👹 **Morbid Creatures: Mutant** |
| `Skin_Mimic_PLACEHOLDER` | 🕷️ **Mimic prototype** |

الطريقة: اسحب موديل الوحش **داخل** الشكل المؤقت (أو بداله بنفس المكان)، احذف الأشكال القديمة،
وتأكد إن مصفوفة `skins` في `MonsterSkinSelector` مرتبطة بالثلاثة الجدد.
كل جولة يطلع الوحش بشكل عشوائي منهم تلقائياً 🎲

### الخريطة
الخريطة الحالية مبنية من مكعبات (بيت بسيط بغرفة وسطية). بدّلها:
- 🏠 **VINTAGE LIVING ROOM 3D GAME PACK** — بيت مسكون داخلي (الأنسب!)
- 🏘️ **lowpoly medieval buildings** أو **The Wasteland LITE** — خرائط خارجية
اسحب الغرف مكان المكعبات، وحرّك المهام ونقاط الظهور (`SpawnPoints`) للأماكن الجديدة.

### شخصية الولد
بدّل الكبسولة الزرقاء (أبو طاقية صفراء 😂) في `Survivor.prefab` بأي شخصية تعجبك.

## 🌐 اللعب عبر الإنترنت (مع ربعك البعيدين)

الأزرار الحالية (Host/Join) تشتغل على نفس الجهاز والشبكة المحلية مباشرة.
للعب عبر الإنترنت عندك خياران:

**الخيار 1 — أسيتات يونتي اللي شريتها (الأفضل):**
1. Package Manager → ثبّت **Multiplayer Services** + أسيت **Multiplayer Session** widgets
2. Edit → Project Settings → **Services**: اربط المشروع بحسابك وفعّل **Relay**
3. اسحب ويدجت **Create Session** و **Join Session by Code** للكانفس —
   تتصل بـ Netcode تلقائياً وتعطيك كود غرفة تشاركه مع الربع

**الخيار 2 — بدون أي إعداد:** افتح البورت 7777 أو استخدم برنامج مثل Radmin VPN/ZeroTier
وخل ربعك يدخلون بعنوانك في خانة العنوان.

## 🎛️ أزرار التحكم

| الزر | الفعل |
|---|---|
| WASD | حركة |
| Shift | ركض (⚠️ يسوي ضجة!) |
| Space | قفز / صياح بالمهمة / طيران الشبح لفوق |
| E | تفاعل مع مهمة أو باب الهروب |
| Q | إلغاء المهمة والهرب 🐔 |
| كلك يسار | هجوم الوحش |

## ⚖️ موازنة اللعب (عدّلها من الـ Inspector)
- سرعة الوحش `8.2` مقابل ركض الولد `7.5` — الوحش أسرع بشوي بس
- حبس الوحش أول `10` ثواني (في `GameManager`)
- قوة ضجة كل مهمة (`noiseLoudness` من 0 إلى 1) ومدتها (`duration`)

## 📝 ملاحظات
- **النصوص العربية**: Unity يعرض العربية بحروف مقطعة افتراضياً. ثبّت أسيت مجاني مثل
  **Arabic Support** وعدّل سطر واحد في `Assets/Scripts/UI/ArabicText.cs` — وكل نصوص اللعبة تنصلح.
- **مهام جديدة**: ورّث من `TaskBase` وشوف الأمثلة في `FunnyTasks.cs` — كلها قابلة للتوسعة.
- **إعادة جولة**: أعد تشغيل اللعبة (أو المشهد) — وإذا تبي زر إعادة داخل اللعبة قولها وأضيفه.
